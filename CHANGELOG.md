# Changelog

## 1.0.0 — Completed hackathon demo

Built for Accel AI Innovate: Paris and the Future Founders: Data-Centric Agents challenge.

- Reconciled synthetic stock, historical usage, planned hospital activity and logistics into one data contract.
- Added a Paris map with hospital requests, social reports and simulated drone deliveries.
- Added optional model selection from feasible transfers, with recorded API receipts and deterministic fallback.
- Added a bounded rolling-horizon scheduler, shortage diagnostics and isolated what-if comparisons.
- Built a responsive React and shadcn/ui interface with recorded replay controls.
- Preserved original sources, the social-only benchmark and measured controller comparisons.
- Published the completed project as Blood in Motion, with setup instructions and explicit limitations.

This release closes the hackathon project. Recorded outcomes are synthetic demonstrations, not clinical validation.
